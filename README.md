# Fun Numbers - Telegram Bot

## Описание

**Fun Numbers** — это Telegram-бот, который предоставляет интересные факты о числах. Пользователь может ввести число, и бот выдаст связанный с ним интересный факт. Бот поддерживает несколько команд для получения фактов о числах, датах, а также для работы с историей запросов.

## Команды

- **/start** — Запустить бота.
- **/help** — Вывести справку по доступным командам.
- **/date** — Узнать интересный факт о дате.
- **/number** — Узнать факт о положительном целом числе.
- **/random** — Узнать интересный факт о числе в заданном диапазоне.
- **/trivia** — Узнать интересный факт, связанный с числом.
- **/history** — Показать краткую историю ответов (последние 10 запросов).

## Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/ваш-username/Fun_numbers.git
   cd Fun_numbers
   ```

2. **Создайте виртуальное окружение и активируйте его:**

   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/MacOS
   venv\Scripts\activate      # Для Windows
   ```

3. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env` в корневой директории проекта и добавьте туда необходимые переменные окружения:**

   ```plaintext
   BOT_TOKEN=ваш_токен_бота
   SITE_API=ваш_api_ключ
   HOST_API=ваш_хост_api
   ```

5. **Запустите бота:**

   ```bash
   python bot.py
   ```

## Используемые технологии

- **Python 3.10**
- **python-dotenv** — для работы с переменными окружения.
- **pyTelegramBotAPI** — для взаимодействия с Telegram API.
- **requests** — для выполнения HTTP-запросов.
- **peewee** — для работы с базой данных.
- **python-dateutil** — для работы с датами.
- **loguru** — для логирования.

## Структура проекта

- **config_data/config.py** — конфигурационные данные и переменные окружения.
- **requirements.txt** — список зависимостей.
- **main.py** — основной файл для запуска бота.
- **requests_history.db** — база данных для хранения истории запросов.

## Пример использования

1. Запустите бота командой `/start`.
2. Введите команду `/number` и следуйте инструкциям, чтобы получить интересный факт о числе.
3. Используйте команду `/history`, чтобы просмотреть последние 10 запросов.
